# Golden reference cases (PROTECTED)

Each directory holds:

- `table.yaml`: a flow table in the format of docs/SEMANTICS.md section 2
- `expected.json`: `stable_reachable` (section 4) and `diagnostics` (section 5), plus a
  human-readable `derivation` explaining every expected entry

Only the repository owner adds or changes these files, using a PR labeled `spec-approved`.
Book examples are transcribed by hand from the book, never generated by an agent.
